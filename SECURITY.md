# Security and private data

Do not open public issues containing taxpayer records, credentials or live
payloads. Report sensitive findings privately through the maintainer's GitHub
profile contact options, with synthetic reproduction steps where possible.

The default workspace is `.data/`, excluded from git. It includes plain SQLite
data and private tokens; protect it and its backups with operating-system
permissions and disk encryption. Do not expose the local API publicly. An agent
token grants full preparation and filing capabilities within the user's scope.

Live submissions require explicit authorization. Preserve accepted receipts,
block ambiguous outcomes, and never add automatic retries after a transmission.
